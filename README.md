# The Open Book 📚

**Stories worth getting lost in.**

The Open Book is a responsive, single-page website for a fictional independent bookstore. The project showcases a curated book collection, staff recommendations, upcoming literary events, and information about the bookstore.

It was developed as a team assignment to practice the fundamentals of HTML5, CSS3, semantic markup, Flexbox, CSS Grid, and responsive web design.

## ✨ Features

* **Responsive Navigation:** Links to the different sections of the page.
* **Hero Section:** Introduces the bookstore and highlights the book of the week.
* **Fiction Collection:** A curated selection of fiction books displayed in a responsive grid.
* **Nonfiction Collection:** Books covering real-world stories, ideas, and personal development.
* **Staff Picks:** Recommendations selected by the bookstore team.
* **Upcoming Events:** Information about author readings, book clubs, and writing workshops.
* **About Section:** Introduces the bookstore and its purpose.
* **Responsive Layout:** Adapts to mobile phones, tablets, and desktop screens.
* **CSS Book Covers:** Decorative book covers created with CSS, without requiring external image assets.

## 🛠️ Technologies

* **HTML5** — Semantic page structure and accessible navigation.
* **CSS3** — Styling, custom properties, transitions, and responsive layouts.
* **Flexbox** — Alignment and layout of navigation elements and event rows.
* **CSS Grid** — Responsive book collections and content sections.
* **Media Queries** — Layout adjustments for different screen sizes.
* **Git & GitHub** — Version control and project hosting.

No JavaScript, CSS frameworks, or UI libraries are required.

## 📁 Project Structure

```text
the-open-book/
├── index.html
├── style.css
└── README.md
```

* `index.html` contains the website's semantic HTML structure and content.
* `style.css` contains the visual styles, CSS variables, layouts, and responsive rules.
* `README.md` documents the project.

## 🚀 Getting Started

No installation or build process is necessary.

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd the-open-book
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for convenient local development.

## 📱 Responsive Design

The website uses a mobile-friendly layout with CSS media queries.

| Screen size | Layout                  |
| ----------- | ----------------------- |
| Desktop     | Four-column book grid   |
| Tablet      | Two-column book grid    |
| Mobile      | Single-column book grid |

The layout is designed to prevent horizontal overflow and maintain readable content across different viewport sizes.

## 🎨 Design System

The project uses CSS custom properties to maintain consistent colors and styling.

| Variable             | Value     | Purpose                |
| -------------------- | --------- | ---------------------- |
| `--color-background` | `#f7f3eb` | Main page background   |
| `--color-surface`    | `#fffdf8` | Card backgrounds       |
| `--color-text`       | `#2c2925` | Primary text           |
| `--color-text-light` | `#756f66` | Secondary text         |
| `--color-accent`     | `#8b4a3c` | Buttons and highlights |
| `--color-border`     | `#ded7ca` | Borders and dividers   |

The visual identity combines warm neutral colors, serif headings, and simple layouts to create a welcoming bookstore aesthetic.

## ♿ HTML & CSS Practices

* Semantic HTML5 landmarks, including `header`, `nav`, `main`, `section`, and `footer`.
* A single primary `h1` heading.
* Internal navigation using section IDs.
* Global `box-sizing: border-box`.
* Reusable CSS custom properties.
* Meaningful heading hierarchy.
* Responsive CSS Grid and Flexbox layouts.
* No external framework dependencies.
